# ADR-001

## Название

Использование локальной AI-модели

## Статус

Принято

## Причина

Записи совещаний содержат рабочую информацию компании.

Передача аудио в облачные сервисы может быть нежелательной.

Поэтому принято решение выполнять распознавание речи и анализ локально.

## Последствия

Плюсы

- Конфиденциальность.
- Работа без интернета.
- Нет оплаты за API.

Минусы

- Требуется более мощный компьютер.
- Локальные модели могут работать медленнее.
