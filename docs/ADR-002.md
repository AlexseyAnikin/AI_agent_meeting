# ADR-002: Консольный интерфейс для первой версии

## Статус

Принято.

## Контекст

Первая версия Meeting AI Agent должна принимать аудиофайл, распознавать речь, формировать отчёт и сохранять результат.

Графический интерфейс увеличит объём работы и усложнит отладку, но не улучшит качество основного процесса обработки совещаний.

## Решение

Первую версию реализовать как консольное приложение.

Пример запуска:

`python main.py meeting.mp3`

Графический интерфейс добавить после завершения и тестирования ядра программы.

## Последствия

Преимущества:

- меньше кода на первом этапе;
- проще тестировать и отлаживать;
- основное внимание уделяется логике обработки совещаний;
- ядро не зависит от конкретного интерфейса;
- в будущем можно добавить GUI, Telegram-бота или другой интерфейс.

Недостатки:

- первая версия будет менее удобна для обычного пользователя;
- путь к аудиофайлу потребуется передавать через терминал.
